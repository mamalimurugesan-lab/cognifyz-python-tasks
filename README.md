# Cognifyz Python Tasks

This repository contains four beginner-friendly Python programs from the Cognifyz internship tasks.

## Tasks

### Task 1 - Basic Text-Based Quiz Game
A simple quiz game using conditional statements and loops.

File: `task1_quiz_game.py`

### Task 2 - Number Pattern Generator
Generates a number pyramid pattern using nested loops.

File: `task2_number_pattern.py`

### Task 3 - Task Manager CRUD Application
A console application implementing Create, Read, Update, and Delete operations using a Python list.

File: `task3_task_crud.py`

### Task 4 - Temperature Converter
Converts temperatures between Celsius and Fahrenheit.

File: `task4_temperature_converter.py`

## How to Run

Make sure Python is installed.

Run any program using:

```bash
python filename.py
```

Example:

```bash
python task1_quiz_game.py
```

## Skills Used

- Python input/output
- Variables and data types
- if/elif/else
- for and while loops
- Lists
- Functions
- Exception handling
- Basic CRUD operations
